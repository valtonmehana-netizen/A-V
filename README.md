# 💞 Love Leap — Valton & Ardiana

A romantic endless runner set in **Taukbashqe Park**, the place of our first date.
Run hand in hand, switch lanes, jump benches, slide under rose arches, and grab
Coca-Cola Zero, Milka, Iced Coffee and Pizza power-ups. Choose Autumn, Winter,
Spring or Summer — all wrapped in a light, dreamy fantasy look.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The finished game is in `dist/`.

## No database

100% static. Scores, coins, outfits and settings are stored only in the
player's browser (`localStorage`). No server, no API keys.

## Deploy (Vercel)

Push to GitHub → vercel.com → Add New Project → import the repo → Deploy.
